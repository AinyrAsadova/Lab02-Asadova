## ПР2. Ответы на контрольные вопросы

**1.** decimal хранит числа точно, а double не совсем точно, там получаются маленькие ошибки. Например 0.1 + 0.2 у double выходит 0.30000000000000004. С деньгами это плохо потому что ошибки копятся, поэтому для денег берут decimal.

**2.** Ошибки не будет, число просто начинает считаться заново с начала. Например у byte 255 + 1 будет 0. Если нужно чтобы была ошибка то надо писать checked.

**3.** В Python переменная может менять тип пока программа работает. А в C# var тип определяется один раз когда компилируется программа и потом уже не меняется. Поэтому var надо сразу задавать значение.

**4.** Всегда string, даже если пользователь ввёл цифры.

**5.** Если ввести буквы то int.Parse выдаёт ошибку FormatException и программа падает. А int.TryParse не падает, он просто говорит false.

**6.** false значит что не получилось превратить строку в число. В переменную out при этом записывается 0.

**7.** TryParse лучше когда число вводит пользователь, потому что он может ошибиться и ввести буквы. Parse в таком случае упадёт, а TryParse можно проверить и попросить ввести ещё раз.
